# Chokchai 4 Yangyont 2002 ERP — โปรแกรมจัดการร้าน โชคชัย 4 ยางยนต์

โปรแกรมหน้าร้านสำหรับอู่ซ่อมรถ ขายยาง ช่วงล่าง และแบตเตอรี่ ใช้งานแบบ **ออฟไลน์** บนเครื่อง Mac และ Windows
(เวอร์ชันแรก 0.1.0)

- สินค้าและสต็อก พร้อมราคาทุนและราคาขาย, หมวดหมู่, ปรับยอดสต็อก, ประวัติการเคลื่อนไหว (stock card)
- บริการพร้อมราคาตั้งต้น
- เปิดบิลขายและบิลซื้อจากสินค้าและบริการ แก้ราคาได้ตอนเปิดบิล, แก้ไขบิลและยกเลิกบิลได้
  - บิลซื้อ: เพิ่มสต็อกและบันทึกต้นทุน · บิลขาย: ตัดสต็อกและบันทึกรายได้
- พิมพ์ใบเสร็จ / ใบแจ้งหนี้ บนกระดาษความร้อน 80 มม. / 58 มม. หรือ A4 / A5 และบันทึกเป็น PDF ได้
- ข้อมูลลูกค้า (ชื่อ, เบอร์โทร, LINE, อีเมล, ชื่อร้านค้า) และประวัติการมาใช้บริการ ค้นหาจากทะเบียนรถได้
- แดชบอร์ดสรุปรายการวันนี้ รายรับ รายจ่าย และรายงานตามช่วงวันที่
- ธีมสว่าง/มืด, สำรองข้อมูลอัตโนมัติทุกวัน และกู้คืนข้อมูลได้
- **ผู้ใช้งานโปรแกรม**: บัญชีเจ้าของร้าน และบัญชีพนักงานที่เลือกสิทธิ์ได้รายคน (เช่น แก้ไขบิล ยกเลิกบิล ดูรายงาน)
  เลือกได้ว่าแต่ละคนใช้รหัสผ่าน/PIN หรือไม่ใช้รหัส (แตะชื่อก็เข้าใช้ได้) พร้อมล็อกหน้าจออัตโนมัติเมื่อไม่ได้ใช้งาน
- **ภาษาไทย / English**: สลับภาษาของโปรแกรมได้ที่ปุ่ม TH/EN มุมขวาบน (หรือ ตั้งค่า → การแสดงผล)
  ส่วนภาษาของใบเสร็จและสลิปเงินเดือนตั้งแยกได้ที่ **ตั้งค่า → การพิมพ์ → ภาษาในเอกสาร**
- **ใครทำอะไร**: ทุกบิลบันทึกว่าใครเปิด แก้ไข รับชำระ หรือยกเลิก, หน้า "ประวัติการแก้ไข" ดูได้ว่าใครแก้อะไร เมื่อไหร่
  (บิล สินค้า บริการ ลูกค้า การตั้งค่า การเข้าสู่ระบบ), สินค้าและบริการมีประวัติราคา (ราคาเดิม → ราคาใหม่ ใครแก้ เมื่อไหร่)
- **พนักงาน**: ข้อมูลส่วนตัว ตำแหน่ง ค่าจ้างรายเดือน/รายวัน บัญชีรับเงิน ประกันสังคม และเงินเบิกล่วงหน้า
- **ลงเวลาทำงาน**: พนักงานแตะชื่อตัวเองที่หน้า "ลงเวลาเข้า-ออกงาน" (ไม่ต้องเข้าสู่ระบบ), สรุปมาสาย ขาด ลา และ OT
  รายเดือน, แก้เวลาที่ลงผิดและบันทึกวันลาได้
- **เงินเดือน**: สร้างงวดเงินเดือน คำนวณจากเวลาทำงาน (หักสาย/ขาด/ลาไม่รับค่าจ้าง ประกันสังคม และเงินเบิก, บวก OT)
  แก้รายการในสลิปได้ บันทึกการจ่าย และพิมพ์สลิปเงินเดือน (A4 / A5 / กระดาษความร้อน)

## ติดตั้งเพื่อใช้งาน

| ระบบ | ไฟล์ | หมายเหตุ |
|---|---|---|
| macOS (Apple Silicon M1/M2/M3…) | `dist/Chokchai-4-Yangyont-2002-ERP-<version>-arm64.dmg` | ครั้งแรกให้คลิกขวาที่แอป → **Open** (macOS 15 ขึ้นไป: เปิดแอปหนึ่งครั้ง แล้วไปที่ System Settings → Privacy & Security → **Open Anyway**) เพราะแอปยังไม่ได้ลงทะเบียนกับ Apple |
| macOS (Intel) | `dist/Chokchai-4-Yangyont-2002-ERP-<version>-x64.dmg` | เหมือนด้านบน |
| Windows 10/11 (64-bit) | `dist/Chokchai-4-Yangyont-2002-ERP-Setup-<version>.exe` | ถ้ามีหน้าต่าง SmartScreen ให้กด "More info" → "Run anyway" |

### เริ่มใช้งานครั้งแรก

1. เปิดโปรแกรมครั้งแรก ระบบจะให้ตั้งชื่อและรหัสผ่านของ **เจ้าของร้าน** (เลือก "ไม่ใช้รหัสผ่าน" ได้ถ้าต้องการแตะชื่อเข้าใช้)
2. ถ้าตั้งรหัสผ่าน ระบบจะแสดง **รหัสกู้คืน** ครั้งเดียว ให้จดใส่กระดาษหรือถ่ายรูปเก็บไว้ ถ้าเจ้าของร้านลืมรหัสผ่าน
   ใช้รหัสนี้ตั้งรหัสผ่านใหม่ได้ที่หน้าเข้าสู่ระบบ (กด "ลืมรหัสผ่าน?")
3. เพิ่มบัญชีพนักงานและเลือกสิทธิ์ได้ที่ **ตั้งค่า → ผู้ใช้งาน** จะให้ใช้รหัสผ่านหรือไม่ก็ได้ ถ้าพนักงานลืมรหัสผ่าน
   เจ้าของร้านตั้งรหัสใหม่ (หรือเปลี่ยนเป็นไม่ใช้รหัส) ให้ได้ที่หน้าเดียวกัน
4. เพิ่มข้อมูลพนักงานที่ **ข้อมูลพนักงาน** และตั้งเวลาเข้างาน วันทำงาน กฎหักสาย/OT/ประกันสังคม ที่
   **ตั้งค่า → เวลางาน & เงินเดือน**

> เวอร์ชัน 0.1.0 เป็นเวอร์ชันแรก ข้อมูลจากตัวทดลองก่อนหน้า (ชื่อ "Chokchai4 ERP") จะไม่ถูกนำมาใช้ และถูกลบเมื่อเปิดโปรแกรม
> ถ้าเครื่อง Mac ยังมีแอป "Chokchai4 ERP" ตัวเก่าอยู่ใน Applications ลบทิ้งได้เลย

### ข้อมูลเก็บอยู่ที่ไหน

- macOS: `~/Library/Application Support/Chokchai 4 Yangyont 2002 ERP/chokchai4.db`
- Windows: `%APPDATA%\Chokchai 4 Yangyont 2002 ERP\chokchai4.db`
- ไฟล์สำรองอัตโนมัติอยู่ในโฟลเดอร์ `backups/` ข้างๆ กัน เปิดโฟลเดอร์ได้จากเมนู **ตั้งค่า → สำรองข้อมูล → เปิดโฟลเดอร์ข้อมูล**

> แนะนำให้กด "สำรองข้อมูลตอนนี้" แล้วเก็บไฟล์ไว้ใน USB หรือ Google Drive เป็นประจำ (อย่างน้อยสัปดาห์ละครั้ง)

### การพิมพ์ใบเสร็จกับเครื่องพิมพ์ความร้อน (Thermal 80 มม.)

1. ติดตั้งไดรเวอร์เครื่องพิมพ์ให้พิมพ์จากเครื่องได้ก่อน
2. ไปที่ **ตั้งค่า → การพิมพ์** เลือกขนาดกระดาษ "80 มม." และเลือกเครื่องพิมพ์
3. ถ้าต้องการให้พิมพ์ทันทีโดยไม่ต้องกดยืนยัน ให้เปิด "พิมพ์ทันทีโดยไม่ถาม"

### เปลี่ยนโลโก้

วางไฟล์โลโก้ (PNG/JPG) ไว้ในเครื่อง แล้วรัน `npm run logo -- /path/to/logo.png` จากนั้น build ใหม่
ไอคอนแอป (โลโก้บนพื้นสี่เหลี่ยมมุมมนสีกรมท่า ขนาดเท่าแอปอื่นใน Dock) และโลโก้ในโปรแกรมจะเปลี่ยนตาม
ส่วนโลโก้บนใบเสร็จอัปโหลดได้ที่ **ตั้งค่า → ข้อมูลร้าน**

## สำหรับนักพัฒนา

ต้องมี Node.js 24 ขึ้นไป

```bash
npm install
npm run dev          # Next dev server + Electron (แก้โค้ดแล้วรีโหลดอัตโนมัติ)
npm test             # unit tests (vitest, in-memory SQLite)
npm run typecheck    # TypeScript
npm run build        # สร้าง out/ (หน้าจอ) + dist-electron/ (main process)
npm start            # เปิดจาก build โดยไม่ต้องทำตัวติดตั้ง
npm run dist:mac     # สร้าง .dmg (arm64 + x64) ใน dist/
npm run dist:win     # สร้างตัวติดตั้ง Windows (.exe) ใน dist/ (build บน Mac ได้)
```

- ถ้าเปิด Electron จาก terminal ของ editor แล้วแอปไม่ขึ้น ให้ตรวจว่าไม่มีตัวแปร `ELECTRON_RUN_AS_NODE` ค้างอยู่
  (สคริปต์ของโปรเจกต์ลบตัวแปรนี้ให้อยู่แล้ว)
- ถ้า vitest ขึ้น "Cannot find native binding" ให้รัน `rm -rf node_modules package-lock.json && npm install`
  (เป็นบั๊กของ npm เรื่อง optional dependency)
- ถ่ายภาพหน้าจอทุกหน้า (โหมดสว่าง/มืด) พร้อมข้อมูลตัวอย่าง: `npm run screenshot -- --demo`
- แก้ schema ฐานข้อมูลที่ `electron/db/schema.ts` แล้วรัน `npm run db:generate` (migration จะรันอัตโนมัติตอนเปิดแอป)
- ข้อความในโปรแกรมเขียนเป็นภาษาไทยใน `tr("…")` แล้วเพิ่มคำแปลภาษาอังกฤษใน `shared/i18n/en.json`
  (`node scripts/i18n.mjs missing` / `add` / `prune`; `npm test` จะแจ้งถ้ายังแปลไม่ครบ)
- GitHub Actions (`.github/workflows/build.yml`) build ตัวติดตั้งบน macOS และ Windows ได้เมื่อ push tag `v*`
